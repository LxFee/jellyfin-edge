# 导出链接契约

主站直连时，下载和复制串流地址沿用 Jellyfin 原生操作；经过已注册代理时，使用
当前节点的导出链接。分享始终生成代理链接。普通播放沿用访问入口，不由导出菜单改写。

## 节点与有效期

从代理访问时使用该节点；主站生成分享链接时使用插件配置的默认节点。
访问上下文由主站核验注册节点身份，网页不使用浏览器 IP 或域名猜测入口。

部署可以让同一域名在局域网进入主站、外网进入代理。`/edge/v1/exports/` 必须始终
进入对应代理，保证分享的播放列表、分片和文件能从局域网及外网打开。

链接默认自创建起有效 7 天，插件配置允许设为不过期。

## 主站离线

主站暂时不可达时，已完整缓存且凭证仍有效的导出链接继续允许观看或下载，由节点校验媒体访问凭证和有效期。未缓存的内容在无法回源时不可用；该离线能力不改变原生 Jellyfin 客户端访问的账号鉴权要求。

## 凭证与权限

导出链接携带的凭证限定到目标媒体、媒体版本及允许的操作，不使用通用 Jellyfin 账号访问 token。原生客户端的日常主站转发继续保留 Jellyfin 鉴权。

生成分享链接时检查影片播放权限；代理下载与原片串流的导出继续检查下载权限。
获得导出链接的观众凭该媒体访问凭证访问对应资源。主站原生下载和串流地址继续使用
Jellyfin 账号鉴权，不能代替供他人访问的分享链接。

## 原生语义

Jellyfin Web 12.2 的“复制串流链接”与“下载”均使用原文件下载地址，且菜单受下载资格控制。代理导出保留这一原片语义和版本选择，不将原片下载自动改成音轨选择或字幕烘焙后的转码输出；兼容性转码与字幕烘焙由分享点播入口提供。[原生菜单实现](https://github.com/jellyfin/jellyfin-web/blob/v12.2/src/components/itemContextMenu.js)
