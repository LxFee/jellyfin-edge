# Jellyfin 代理需求边界

项目聚焦 Jellyfin，形态为 Jellyfin 插件与代理节点。插件是唯一配置入口，负责管理并向节点下发配置；代理节点注册接入，不提供独立控制面。B 站点播与 OBS 推流退出项目范围。

当前版本面向 Jellyfin Server / Web 12.2。

## 主站转发

客户端通过代理节点访问 Jellyfin 主站，保留原有账号鉴权。直接播放和下载使用自建缓存，插件提供文件大小、最后修改时间和路径作为缓存身份信息；需要转码时由主站执行，代理转发该输出而不缓存。不依赖 JuiceFS。

## 分享点播

分享点播通过 Jellyfin 媒体菜单生成链接，替代独立代理网页中的手动添加与生成入口。原代理网页的配置迁入 Jellyfin 插件配置页面，代理节点接收配置、执行缓存与分发。输出方式见 [点播输出](vod-output.md)，缓存契约见 [缓存身份](cache-identity.md)。

媒体项目菜单中的生成与复制入口只支持 Jellyfin Web 网页端，通过网页端扩展调用插件接口。拥有该视频播放权限的用户均可生成分享链接；观众凭链接观看，无需登录 Jellyfin。

## 导出链接

分享链接、下载链接和复制出的串流链接经代理生成时，统一使用限定到指定媒体、版本和操作的凭证，节点选择与有效期规则见 [导出链接契约](exported-links.md)。
