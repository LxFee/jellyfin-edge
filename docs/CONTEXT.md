# Jellyfin 代理领域术语

本项目通过 Jellyfin 插件与代理节点为媒体访问提供缓存与分发。本文只定义领域术语。

## 来源与访问

**Jellyfin 主站**：保存媒体库、处理用户权限并执行 Jellyfin 转码的服务。

**代理节点**：注册到 Jellyfin 插件、接受其配置，并承接媒体请求、缓存与分发的服务节点。

**插件配置**：通过 Jellyfin 插件管理并下发给已注册代理节点的运行配置。

**默认节点**：从 Jellyfin 主站访问时，用于生成导出链接的指定代理节点。

**导出链接**：用于向播放器或观众提供媒体访问入口的链接，包括分享链接、下载链接和复制的串流链接。

**媒体访问凭证**：授予指定媒体、版本和操作访问权的凭证，有效期由导出链接策略确定，不具备通用账号访问权限。

**主站转发**：通过代理节点访问 Jellyfin 主站的访问方式，保留 Jellyfin 原有播放和下载行为。

**点播链接**：分享会话的统一形式播放入口；不同来源的媒体格式可以不同。

**分享会话**：保存创建时的来源版本与输出选择的点播内容记录；观众凭其链接观看。
_避免_：与某位观众临时建立的播放会话混用。

## 媒体与缓存

**原文件缓存**：Jellyfin 直接播放或下载时，对源媒体文件内容的缓存。

**转码缓存**：点播链接对应的转码输出缓存，区别于原文件缓存。

**媒体版本**：某个来源内容在特定状态下的身份，由分享会话保存的版本信息描述。

**字幕烘焙**：把选定字幕绘制进视频画面的处理。
_避免_：与可切换的字幕轨道混用。
