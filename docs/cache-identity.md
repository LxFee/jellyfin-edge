# 缓存身份

分享会话保存创建时可获取的来源版本信息和输出选择，代表一个特定版本的点播内容。点播链接标识该分享会话，缓存键由会话保存的信息生成，用于识别可复用的内容版本。

Jellyfin 插件提供文件路径、大小和最后修改时间，作为原文件版本身份的信息。源文件版本变化后，对应不同的缓存版本，不将旧缓存数据与新版本回源数据混合。

转码缓存身份覆盖分享会话的产物身份、源视频版本、视频编码与分辨率/码率、音频输出参数以及选定的音轨和字幕。能够取得外挂字幕文件版本时，将其版本信息纳入；内封轨道随源视频版本识别。无法取得的版本信息遵守下述一致性边界。

## 一致性边界

通过版本信息和缓存键尽力避免内容混用，不承诺源文件或转码产物的强一致性。缓存键仍无法覆盖的更新不一致问题采用尽力而为原则；重新生成点播链接和清空缓存作为手动兜底，不要求为消除全部此类风险而保存完整源版本快照。
