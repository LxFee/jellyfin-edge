# 兼容与验证范围

当前版本支持 Jellyfin Server / Web 12.2、.NET 10；发布的主站和代理容器支持 Linux amd64。网页菜单适配对应 Web 页面结构，其他版本需要重新验证。

## 自动验证

- C# 插件测试：注册与轮换、持久化、来源命名空间、媒体授权范围、到期与撤销、分页与批量撤销、用户下载权限。
- Python 网关测试：HTTP 透明转发、Range/HEAD/条件请求、缓存并发与失败填充、容量/LRU/重启、权限隔离、HLS、下载与 WebSocket。
- 主站入口测试：插件安装、外部脚本副本与参数处理。
- 发布集成：在隔离 Docker 网络和合成媒体上验证真实主站、代理与 HTTP 请求，测试通过后才发布同一批镜像。

截图使用隔离演示实例，展示配置页、节点与链接列表及真实网页菜单。

## 行为边界

原文件直接播放和下载可缓存；普通播放转码继续回主站。分享转码由主站执行，节点缓存 HLS / MPEG-TS；默认 H.264 / AAC，可选 HEVC 或原文件。选定字幕由主站烘焙。

完整缓存的导出可在主站离线时读取；原生账号播放依赖主站。离线期间节点无法即时获知撤销或媒体变化，缺失缓存也无法回源。[导出边界](exported-links.md)

尚未完整覆盖移动端所有菜单、第三方原生客户端的导出界面、AVPro 运行环境以及所有 GPU/编码器组合。媒体播放器需要支持实际输出格式；项目未设置播放器专用处理。
